## Explicit interface

`nn transcript artifact read <session> <agent-id> --event <exact-event-id> --snapshot <diagnostic-snapshot> --finding <one-based-index> --allow-root <absolute-directory>`.

Caller obtains the snapshot from `nn transcript events <session> <agent-id> --diagnostics --event <exact-event-id>` with default facets and no `--payload`. A snapshot from a window, `--last`, custom `--select`, or `--payload` is *not* interchangeable; obtain the exact-event snapshot first. No path flag: the chosen finding must have an artifact reference, and the path is taken only from that freshly recomputed diagnostic. Require all flags explicitly; non-TTY behavior is identical. No browsing, prompting, shell, editor, network, notebook write, recursive reference following, or sidechain resolver reuse. Return one JSON envelope, not a modification of the event.

Before any artifact path access: reacquire the selected agent's retained ledger using existing ownership checks, recompute the exact-event default diagnostic snapshot using the same `buildLedgerPageUsing` projection (complete internal event without fragment transport), compare caller snapshot, then select the one-based finding and require a nonempty recorded path. Event ID alone never authorizes a read. Snapshot comparison establishes only current retained-projection equality, not producer authenticity or historical artifact identity. If target/diagnostic/reference unavailable or snapshot mismatched, return typed error and perform zero artifact path opens/stats.

## Admission and acquisition

Require `--allow-root` and recorded path to be absolute *local filesystem* paths with no NUL, URI scheme, empty/dot/dotdot components, or lexical aliases. The root must be a directory; reject root or target symlinks in **every** component. Reject target outside the root using component-wise lexical relativity before any path open. Never use `EvalSymlinks`, path-prefix matching, or check-then-open. On Darwin/Linux, start from a descriptor for `/` and walk every component via `openat` with `O_DIRECTORY|O_NOFOLLOW|O_CLOEXEC` for directories; open the leaf relative to the admitted parent descriptor with `O_RDONLY|O_NOFOLLOW|O_NONBLOCK|O_CLOEXEC`. Check `fstat` on the opened leaf and require a regular file before reading. Close every descriptor. Unsupported platforms fail closed at compile/runtime with a typed unsupported result; never silently fall back to ordinary `os.Open`. An approved root containing a symlink (e.g. macOS `/var`) is rejected; callers can approve a symlink-free canonical spelling explicitly. A later path swap cannot redirect an already opened descriptor outside the approved directory chain. This does not prevent writes to the same inode or prove historical identity.

Hard maximum acquired content: 16,384 bytes, with at most one extra byte read to detect truncation; fixed bound, no flag to raise it in v1. Encode acquired bytes as base64 in a bounded JSON envelope, with `sha256` of **acquired bytes only**, measured count, `coverage=complete|partial|unstable`, and measured size when available. If >16,384, return only the 16,384-byte prefix with partial coverage, never a whole-file digest claim. Compare descriptor metadata before and after acquisition; report detectable change as unstable rather than complete. An undetectable concurrent change remains possible and must not be described as historically identical. A successful read is a new acquisition of present bytes, not recovered historical transcript bytes.

Result includes version, exact event ID, diagnostic snapshot, finding index, finding location/kind, verbatim recorded path (JSON-escaped), approved root, acquired byte count, base64 bytes, prefix digest, coverage, and explicit current-acquisition/historical-identity qualification. Errors distinguish missing, denied, nonregular, unsupported platform, stale snapshot, invalid request, and read failure; do not reflect sensitive contents in errors. A failure must not alter the recorded upstream tool result.

## Test-first guard and ownership

Write new tests for: no artifact opener invocation on missing root, stale snapshot, wrong event/reference; one admitted ordinary file with exact bytes/base64/digest; at/over bound with partial prefix; missing/denied; relative path, traversal, URI, outside sibling, symlink in root/intermediate/leaf, directory/FIFO/socket; denied attempts return no content; file replacement race and detectable in-place mutation; no nested-reference following; Pi foreign sidechain remains excluded. Use an injected `artifactOpener` parameter/interface for zero-I/O tests and real temp directories for descriptor traversal. Adversarial swap test must replace a path component while concurrent opens run and assert no outside bytes are returned; a timing-only test cannot prove all races but must exercise the no-follow design. Establish assertion-specific compiling RED before production implementation, then GREEN. Test unsupported-platform build contract if feasible; no cross-platform permissive fallback.

One writer owns new reader command and OS-specific admission files/tests plus the one-line registration change in `cmd/nn/cmd/transcript.go`; no recognizer, existing event command, Pi sidechain, or index mutation. If exact-event snapshot cannot be reproduced without changing existing event output/hashing, stop. If descriptor-relative no-follow traversal is unavailable on a target platform, fail closed and report rather than weakening admission. Focused reader tests then owning package, vet, gofmt, diff checks, and existing raw/Pi/export compatibility tests. Parent inspects attributable RED/GREEN transcript, actual diff, and security tests before acceptance. Do not change ADR status or claim reader is shipped until acceptance.

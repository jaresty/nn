# ADR-0059: Parent-only roster acquisition for Pi observation

Status: Accepted; native guards verified (see ../transcript-initial-acquisition-verification.md)

Normal Pi observation chooses its readable children from parent-record topology,
without hydrating every worker's usage/cost history through the general tree
command. Preserve canonical direct-child ordering, membership, descriptions,
omission counts and parentage rules using the existing tree projection.

Share the captured parent prefix with attention acquisition. The roster receipt
must explicitly say that worker usage was not hydrated; it is not the receipt of
a full usage-enriched tree read. Readable event tails retain their existing native
commands and bounds. Other transcript schemas retain normal tree construction.

Verify sample parity with native tree selection, zero worker-body reads during
roster discovery, and existing observation/replay contracts. Compare complete
observation on the same frozen source set before attributing performance gains.
